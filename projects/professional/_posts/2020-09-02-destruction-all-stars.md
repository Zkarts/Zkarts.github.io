For Wushu Studios, my first project was Destruction All-Stars, a character-based vehicle destruction derby game. Our two main projects on this title were the level creation mode and the Combo System we added to the game afterwards to increase the skill ceiling of the game.

### Summary of work
- Slate UI for the level creation mode
- Gameplay logic for the creation mode
- Gameplay logic for the Combo System
- 2D particle effects work for the shards in the Combo Update
- UMG UI work
- Networking code
- Testing and debugging on a PS5 devkit
